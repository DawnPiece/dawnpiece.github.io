# Telporter

The Teleporter is an NPC that will be located at the original start point of each island. You can speak to this NPC to traverse around the world. If you are far from the teleporter and need to fast travel, then you can always type /spawn to return to Spawn Island and teleport from there.

## Locations

In the teleporter menu, you will notice the first island and first POI on the island is unlocked. As you complete the main quest on each island, the next islands first POI will automatically be unlocked. You can unlock more POI's on islands by completing quests. Simply click the location and it will tell you which quest you need to complete to unlock the POI.
