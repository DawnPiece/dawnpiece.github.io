# Jails

Jails are locations throughout the world that have a Policeman NPC. The Policeman NPC will explain the purpose of the Jail and the rules for the server as well. If a player breaks the rules for the server, they have the possibility to be jailed for a limited time and will be sent to the biggest jail cell at the specified jail. Some jails will have multiple smaller cells with citizens related to the discoveries system.
