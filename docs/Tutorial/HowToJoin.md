# How To Join

Please follow the steps below using your preferred application to join the server. 

## CurseForge

The CurseForge App is a place to store various instances of all kinds of modpacks for different versions of the servers you play so you can access them in one place.

### First Time Download Steps

1. [Download and Install the CurseForge App](https://www.curseforge.com/download/app). 
2. Open the CurseForge App, login with your Microsoft Account and create your personalized interface.
3. Click the three dots, the open game settings. In this menu scroll down to allocated memory and select 4096 MB. Feel free to adjust this to your desired values, but make sure to never allocated more than half of your computers total RAM.
4. [Download the ModPack](https://drive.google.com/drive/folders/1yP-n2PLM-Xb2jszd5skHZi0dG0y95B0f?usp=sharing)
5. On the CurseForge App under the My Modpacks tab, select Import, then click Choose .zip file and upload the zip file from the link above. Make sure to check the box and download all files. Do not click download CurseForge Files Only.
6. Launch the modpack and join in on the fun! The server is directly accessible from the home screen.

### Update Steps

If you don't want to download the instance and delete the old one every time there is an update, follow the steps below for easy updates.

1. [Download the latest version of Dawnpiece](https://drive.google.com/drive/folders/1GaQh20ZMCRrjlHOGbCA8HcB-b5ShGBNT?usp=sharing). Sometimes there may be additonal updates to other mods so make sure those are updated as well if it's announced.
2. On the CurseForge App, right click the modpack, select Open Folder, open the mods folder and swap out the older version of the mod with the new one.
3. Once complete, click launch and the updated version should be good to go.

## Prism Launcher

The Prism Launcher is a place to store various instances of all kinds of modpacks for different versions of the servers you play so you can access them in one place.

### First Time Download Steps

1. [Download and Install the Prism Launcher](https://prismlauncher.org/download). 
2. Open the Prism Launcher, login with your Microsoft Account and create your personalized interface.
3. Click Settings, the Java and set your minimum memory to 2048 MiB and maximum memory to 3584 MiB. Feel free to adjust these values based on your computer settings. Prism Launcher will tell you if you allocated too much as well. Remember to never allocate more than half of your systems RAM to the launcher.
4. [Download the ModPack](https://drive.google.com/drive/folders/1XdqlaD6bPUdxfKQR-1Y9F1VHwnhsEo3h?usp=sharing)
5. On the Prism Launcher, click Add Instance, then click Import, select the downloaded zip file and click OK.
6. Launch the modpack and join in on the fun! The server is directly accessible from the home screen.

### Update Steps

If you don't want to download the instance and delete the old one every time there is an update, follow the steps below for easy updates.

1. [Download the latest version of Dawnpiece](https://drive.google.com/drive/folders/1GaQh20ZMCRrjlHOGbCA8HcB-b5ShGBNT?usp=sharing). Sometimes there may be additonal updates to other mods so make sure those are updated as well if it's announced.
2. On the Prism Launcher, select the instance, click edit, and select the mods tab.
3. Remove the old version of the mod that has been updated, then click add file to add the updated version.
4. Once complete, click launch and the updated version should be good to go.

## Minecraft Launcher

The original launcher is a bit more difficult to set up but easy to update. If you prefer the classic way to set up a Minecraft Modpack then follow the steps below.

### First Time Download Steps

1. [Download and Install NeoForge](https://neoforged.net/). Make sure you select Minecraft Version 1.21.1 and Neoforge Version 21.1.228.
2. Open up your Minecraft Launcher, select installations and run the new NeoForge installation you had set up. After you run the installation, close out of Minecraft.
3. Make sure to allocate your appropriate RAM. On the insallations tab, select the NeoForge version you just set up, click the three dots, and change the JVM arguments to your ideal RAM. Default should be -Xmx2G so start by changing it to -Xmx4G and adjust later on if you need more of less. Remember to never allocate more than half of your systems RAM to the launcher.
4. [Download the Mods](https://drive.google.com/drive/folders/1GaQh20ZMCRrjlHOGbCA8HcB-b5ShGBNT?usp=sharing).
5. For Windows, place all of the mods in your %appdata%\.minecraft\mods folder. For Mac, place the mods in the /Library/Application Support/minecraft/mods folder.
6. Launch the modpack and join in on the fun! The server is directly accessible from the home screen.

### Update Steps

1. [Download the latest version of Dawnpiece](https://drive.google.com/drive/folders/1GaQh20ZMCRrjlHOGbCA8HcB-b5ShGBNT?usp=sharing). Sometimes there may be additonal updates to other mods so make sure those are updated as well if it's announced.
2. For Windows, delete the old version of the updated mods in your %appdata%\.minecraft\mods folder. For Mac, delete the old version of the updated mods in the /Library/Application Support/minecraft/mods folder.
3. Add the updated version jar file to the folder.
4. Once complete, click launch and the updated version should be good to go.
